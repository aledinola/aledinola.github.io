# Alessandro Di Nola — website migration files

Source documents for `aledinola.github.io`, using the existing website at
https://sites.google.com/site/alessandrodinolaphd/ as the content source.

This is the file-collection stage only. The website layout has not been created
and GitHub Pages has not been enabled. The recovered files are stored in this repository.

- `files/cv/`: existing CV.
- `files/research/`: exact research PDFs linked from the existing site.
- `files/teaching/`: retrieved syllabi and teaching evaluation PDF.
- `content/`: captured source text and source fragments, including owner-approved
  editorial corrections recorded in `migration/CONTENT-EDITS.md`.
- `migration/INVENTORY.md`: results and unresolved links.
- `migration/files.json`: source URLs, original names, sizes, and SHA-256 checksums.
- `migration/links.csv` and `migration/links.json`: source-to-local link inventory.

20 PDFs were recovered. 31 legacy Google Sites viewer links, 2 Dropbox links,
and the homepage photo remain unresolved. See the inventory for details.
